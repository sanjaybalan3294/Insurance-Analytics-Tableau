# Insurance Analytics Dashboard – Tableau

## 📊 Project Overview

This project analyzes insurance data using Tableau to generate
business insights related to customers, policies, premiums, claims,
payments, and policy expirations.

The dashboard provides an interactive view of insurance performance
across customer demographics, policy types, premium trends, claims,
and payment status.

## 🛠️ Tools & Technologies

- Tableau
- Data Visualization
- Data Analysis
- Dashboard Design
- Calculated Fields

## 🎯 Project Objectives

- Analyze insurance policy distribution.
- Understand customer demographics.
- Compare policies by age group and gender.
- Analyze policy types and expirations.
- Track premium trends.
- Analyze claims and payment status.
- Generate business insights through interactive dashboards.
